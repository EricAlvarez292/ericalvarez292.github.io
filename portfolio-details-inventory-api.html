About

A RESTful CRUD API case study for inventory management, covering users, suppliers, products, purchase/sale transactions, and stock levels. Recording a transaction automatically updates the stock on hand for every item in it.

Features JWT bearer authentication, product filtering and sorting, soft deletes, and versioned endpoints (/api/v1) documented with OpenAPI 3 / Swagger UI. Deployed serverless on Vercel with a Neon-hosted PostgreSQL database.

Tech Stack

Node.js Express.js PostgreSQL pg-promise JWT OpenAPI / Swagger Vercel Neon
